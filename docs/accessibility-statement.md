## English

# Accessibility statement for [CHAPTER NAME]

[CHAPTER NAME] is committed to making this website usable by everyone,
including people who use assistive technology, people with low vision or
color-vision differences, people who navigate by keyboard, and people who
prefer less motion. Access to organizing information should not depend on
ability, device, or language.

### Conformance status

The [Web Content Accessibility Guidelines (WCAG) 2.2](https://www.w3.org/TR/WCAG22/)
define requirements for designers and developers to improve accessibility for
people with disabilities. They define three levels of conformance: A, AA, and
AAA.

This website is **[fully / partially] conformant with WCAG 2.2 level AA**.
[Partially conformant means that some parts of the content do not fully
conform to the standard. See "Known limitations" below.]

### What we do to support accessibility

- **Built-in display controls.** The "Aa" button in the site header lets you
  increase the text size (three steps), switch to a high-contrast color scheme,
  and reduce animation. Your choices are remembered on this device only.
- **Keyboard access.** Every link, button, menu, dialog, and form control can
  be reached and operated with a keyboard alone. A "Skip to content" link is
  the first focusable element on every page.
- **Clear structure.** Pages use meaningful headings, landmarks, and labels
  so screen readers can move through them quickly.
- **Color and contrast.** Text and interface elements meet or exceed the AA
  contrast ratios. Information is never conveyed by color alone.
- **Reduced motion.** We honor your operating system's "reduce motion"
  setting and offer our own toggle. Nothing flashes, and nothing plays
  automatically.
- **Two languages.** The full site is available in English and Spanish, with
  correct language markup so screen readers pronounce each page correctly.
- **Events in more than one format.** The calendar can be viewed as a month
  grid or a plain list, and every event can be added to your own calendar
  application.
- **Images and media.** Photos carry text alternatives written by our editors.
  Video posts include [captions / a transcript link].
- **No tracking.** This site sets no analytics or advertising trackers. The
  only stored data is your own display preferences, kept in your browser.
- **Testing.** Automated accessibility checks run on every code change, and
  we test manually with [screen readers / keyboard only / browser zoom to
  400%] before major releases.

## Español

# Declaración de accesibilidad de [NOMBRE DEL CAPÍTULO]

[NOMBRE DEL CAPÍTULO] se compromete a que este sitio web pueda ser usado por
todas las personas, incluidas quienes usan tecnologías de apoyo, quienes tienen
baja visión o diferencias en la percepción del color, quienes navegan con el
teclado y quienes prefieren menos movimiento en pantalla. El acceso a la
información organizativa no debe depender de la capacidad, el dispositivo ni
el idioma.

### Estado de conformidad

Las [Pautas de Accesibilidad para el Contenido Web (WCAG) 2.2](https://www.w3.org/TR/WCAG22/)
definen los requisitos para que diseñadores y desarrolladores mejoren la
accesibilidad para las personas con discapacidad. Establecen tres niveles de
conformidad: A, AA y AAA.

Este sitio web es **[totalmente / parcialmente] conforme con el nivel AA de
las WCAG 2.2**. [Parcialmente conforme significa que algunas partes del
contenido no cumplen por completo con la norma. Consulta «Limitaciones
conocidas» más abajo.]

### Qué hacemos para apoyar la accesibilidad

- **Controles de visualización integrados.** El botón «Aa» en el encabezado
  permite aumentar el tamaño del texto (tres niveles), activar un esquema de
  alto contraste y reducir las animaciones. Tus preferencias se guardan solo en
  este dispositivo.
- **Acceso por teclado.** Todos los enlaces, botones, menús, diálogos y
  campos de formulario se pueden alcanzar y usar únicamente con el teclado. Un
  enlace «Saltar al contenido» es el primer elemento enfocable de cada página.
- **Estructura clara.** Las páginas usan encabezados, regiones y etiquetas
  con significado para que los lectores de pantalla puedan recorrerlas con
  rapidez.
- **Color y contraste.** El texto y los elementos de la interfaz cumplen o
  superan las relaciones de contraste del nivel AA. La información nunca se
  transmite solo mediante el color.
- **Menos movimiento.** Respetamos la configuración «reducir movimiento» de
  tu sistema operativo y ofrecemos nuestro propio interruptor. Nada parpadea
  ni se reproduce automáticamente.
- **Dos idiomas.** Todo el sitio está disponible en inglés y español, con el
  marcado de idioma correcto para que los lectores de pantalla pronuncien
  bien cada página.
- **Eventos en más de un formato.** El calendario se puede ver como
  cuadrícula mensual o como lista simple, y cada evento puede agregarse a tu
  propia aplicación de calendario.
- **Imágenes y medios.** Las fotos llevan alternativas de texto escritas por
  nuestro equipo editorial. Las publicaciones con video incluyen [subtítulos /
  un enlace a la transcripción].
- **Sin rastreo.** Este sitio no instala rastreadores de analítica ni de
  publicidad. Los únicos datos que se guardan son tus preferencias de
  visualización, en tu propio navegador.
- **Pruebas.** Se ejecutan verificaciones automáticas de accesibilidad con
  cada cambio en el código, y realizamos pruebas manuales con [lectores de
  pantalla / solo teclado / zoom del navegador al 400 %] antes de cada versión
  importante.
